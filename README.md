# Clothing71 — Full-Stack E-Commerce Platform

A modern, responsive ecommerce platform developed for Clothing71, a Bangladesh-based clothing brand. The project provides a customer-facing storefront and a dedicated administration system for managing products, inventory and orders.

**Live Website:** https://www.clothing71bd.com/

## Project Overview

Clothing71 was developed to deliver a seamless online shopping experience while providing the business with tools to manage its ecommerce operations.

The platform combines a responsive storefront, product catalog, secure authentication, inventory management, checkout functionality and an administrative dashboard.

## Tech Stack

- **Frontend:** Next.js 16, React 19, TypeScript, Tailwind CSS
- **Backend:** Next.js API Routes, Server-Side Logic
- **Database:** Supabase PostgreSQL
- **Authentication:** Supabase Auth
- **Storage:** Supabase Storage
- **Deployment:** cPanel, CloudLinux, Node.js, LiteSpeed
- **Version Control:** Git and GitHub

## Key Features

### Customer Experience
- Responsive desktop and mobile storefront
- Product categories and collections
- Product image galleries and interactive zoom
- Product variants, colors and sizes
- Shopping cart and wishlist
- Promotional discount functionality
- Cash on Delivery checkout
- Customer accounts and order tracking

### Administration
- Product creation, editing and publication
- Product image and gallery management
- Inventory and stock management
- Order management and fulfillment
- Staff access controls
- Courier tracking and manual Pathao fulfillment workflows

### SEO and Optimization
- Dynamic product metadata
- XML sitemap and robots.txt
- Google Search Console integration
- Product structured data
- Responsive image handling
- Next.js standalone production deployment
